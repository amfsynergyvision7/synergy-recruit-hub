**13 November 2026 | AMF Synergy Vision | Draft PR #12 | RELEASE HOLD**

## This build's actual source changes

Build84 fixes **real draft application code**, not only a design memo or synthetic fixture:

1. **Reusable bounded network downloader** — `src/lib/safe-remote-download.server.ts` is a server-only, no-credential GET implementation with an exact approved HTTPS-host predicate **checked at every redirect hop**, maximum four redirects, no private/local/IP/HTTP/custom-port URLs, no forwarding credentials, an AbortSignal request timeout, a Content-Length precheck and a streaming byte counter that cancels unbounded bodies. It separately provides a 1-MB-ceiling response-text reader to prevent arbitrary provider JSON bodies from being held in memory.
2. **Google Drive resume files** — `src/lib/resume-fetch.server.ts` parses only genuine `https://drive.google.com/file/d/...`, `/open?id=...`, or `/uc?id=...` links with valid file IDs. Downloaded files must traverse only Google Drive/Googleusercontent service hosts and are limited to **8 MB / 15 seconds per request / four redirects**, including virus-scanner interstitial confirmation. The actual bytes must have PDF `%PDF` or ZIP/DOCX `PK` magic; ordinary HTML, arbitrary binary and obsolete .doc/OLE are rejected *before* parsing. Raw provider error details are not reflected into candidate-facing messages. PDFs/docx remain subject to parser and privacy release holds.
3. **Letterhead/logo fetch** — `src/lib/resume-pdf.server.ts` no longer `fetch()`es arbitrary app-settings URLs. The logo must be a *public object* under the **current deployment's own Supabase Storage HTTPS origin**, never a signed/private object URL, localhost or other host. It is limited to **512 KB / 5 seconds / zero redirects** and requires actual PNG/JPEG magic bytes (and compatible MIME when present). Any failure produces the existing safe **text-only letterhead**, with no provider error reflection.
4. **Google Drive folder listing** — `src/lib/drive-import.server.ts` validates exact `https://drive.google.com` folder URLs rather than substring matching; its Google API listing is restricted to **www.googleapis.com**, maximum **2 MB / 10 seconds / zero redirects**, **10 pages**, a bounded pagination token, and detection of repeated pagination tokens. Provider response bodies and API keys do not appear in returned error messages. Existing `drive_bulk_import` server release hold remains active.
5. **Gemini inference responses** — `src/lib/ai.server.ts` rejects HTTP redirects that could send `x-goog-api-key` to a different origin, uses a **30-second request timeout**, and parses only up to **512 KB** of streamed response JSON. Raw candidate prompt text and provider error bodies remain excluded from exceptions. The preexisting `candidate_ai_processing` privacy-release hold continues to block all five user-callable AI entrypoints.
